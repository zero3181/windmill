# Google Play 등록 자료 — 풍차돌리기 1.0

Play Console의 각 칸에 그대로 붙여 넣을 수 있게 정리했습니다. 글자 수는 Play 제한 안에 맞췄습니다.

## Play Console 등록 순서

### 1. 앱 만들기

Play Console › **모든 앱** › **앱 만들기**

| 칸 | 입력 |
| --- | --- |
| 앱 이름 | 풍차돌리기 |
| 기본 언어 | 한국어 – ko-KR |
| 앱 또는 게임 | 앱 |
| 무료 또는 유료 | 무료 (나중에 유료로 바꿀 수 없음) |
| 선언 | 개발자 프로그램 정책, 미국 수출 법규 두 항목 체크 |

### 2. 앱 설정 (대시보드 › 앱 설정 · 왼쪽 메뉴 › 정책 › 앱 콘텐츠)

대시보드의 할 일 목록을 위에서부터 채웁니다. 답은 아래 [앱 콘텐츠](#앱-콘텐츠-정책) 표에 있습니다.

1. 개인정보처리방침 URL
2. 앱 액세스: 모든 기능을 특별한 액세스 없이 이용 가능
3. 광고: 아니요
4. 콘텐츠 등급: 설문 작성 (이메일 입력 → 카테고리 → 모두 아니요)
5. 타겟층 및 콘텐츠: 18세 이상
6. 뉴스 앱: 아니요
7. 데이터 보안: 수집·공유하는 데이터 없음
8. 정부 앱: 아니요
9. 금융 기능: **앱에서 금융 기능을 제공하지 않음** (대출·은행 업무·결제·송금·투자·보험 없음)
10. 건강: 해당 없음
11. 앱 카테고리와 연락처: 금융, 연락처 이메일
12. 기본 스토어 등록정보: 이름·짧은 설명·자세한 설명·아이콘·그래픽 이미지·휴대폰 스크린샷

### 3. 테스트 버전 올리기 (첫 aab 업로드)

**테스트 및 출시 › 테스트 › 내부 테스트 › 새 버전 만들기**

1. "Play 앱 서명"을 묻으면 **Google에서 생성한 앱 서명 키 사용**(기본값)으로 계속합니다. 업로드 키는 Expo(EAS)가 보관하고 있습니다.
2. App Bundle: 다운로드 폴더의 `pungcha-1.0.0-vc4.aab`를 올립니다 (버전 1.0.0, versionCode 4).
3. 출시 이름은 자동(4 (1.0.0)), 출시 노트: `첫 버전입니다.`
4. **테스터** 탭에서 이메일 목록을 만들어 본인을 넣고 저장 → 출시 검토 → 출시.

### 4. 프로덕션 출시

- **개인 개발자 계정을 2023년 11월 이후에 만들었다면**, 프로덕션 전에 비공개 테스트에서 테스터 12명 이상이 14일 동안 참여해야 프로덕션 신청이 열립니다 (대시보드 › 프로덕션 액세스 신청). 조직 계정이거나 그 전에 만든 계정이면 바로 프로덕션에 올릴 수 있습니다.
- 프로덕션 › 새 버전 만들기 → 같은 aab(또는 내부 테스트 버전 승격) → 국가: 대한민국 → 검토를 위해 전송.
- 첫 검토는 보통 며칠 걸립니다.

## 자세한 설명 (4,000자)

```
풍차돌리기는 매달 예·적금을 하나씩 새로 가입해서, 1년 뒤부터 매달 만기를 받는 저축법이에요. 처음 하는 사람도 헷갈리지 않게 할 일만 차례로 알려드려요.

■ 날개 수와 금액만 정하면 시작
적금 풍차인지 예금 풍차인지, 날개를 몇 개 달지(6개월·12개월), 매달 얼마를 저금할지만 고르세요. 계좌 하나에 얼마씩 넣으면 되는지, 매달 넣는 돈이 어떻게 늘어나는지 바로 보여 드려요.

■ 이번 달 할 일만 따라 하면 돼요
"7번째 적금을 가입하세요"처럼 지금 할 일 하나만 보여 드려요. 가입했다면 할 일을 누르고 은행과 금리만 확인하면 끝이에요. 다음 가입 날을 골라 두면 그날 오전 9시에 알려 드려요.

■ 날개 하나가 만기 한 달
풍차의 날개 하나는 1년 중 한 달을 뜻해요. 만기가 다른 계좌를 가입할 때마다 그 달의 날개가 채워지고, 12개가 모두 차면 풍차가 돌아가요. 매달 만기가 돌아온다는 뜻이에요.

■ 처음이어도 괜찮아요
메뉴의 '풍차돌리기란?'에서 개념과 장점을 그림으로 쉽게 설명해 드려요.

■ 내 계좌를 한눈에
가입한 계좌의 가입일부터 만기일까지를 그래프로 보여 드리고, 만기까지 남은 날을 알려 드려요. 만기 7일 전과 만기 당일, 원하면 적금 납입일에도 알림을 받을 수 있어요.

■ 금리 높은 상품 찾기
금융감독원 '금융상품한눈에' 공시를 바탕으로 은행·저축은행 예·적금을 기본 금리 순으로 보여 드려요. 마음에 드는 상품을 고르면 은행·상품명·금리가 가입 정보에 바로 채워져요.

■ 내 정보는 내 기기에만
은행 계좌와 연결하지 않아요. 입력한 내용은 이 기기에만 저장되고, 백업 파일로 직접 옮길 수 있어요. 회원가입도 필요 없어요. 원하면 생체 인증으로 앱을 잠글 수 있어요.

※ 금리와 예상 이자는 참고용이에요. 실제 가입 조건과 금리는 가입 전에 금융회사에서 확인해 주세요.
```

### 데이터 보안

- 데이터 수집: **아니요** (사용자 데이터를 수집하거나 공유하지 않음)
- 근거
  - 계좌·설정은 기기 안 SQLite에만 저장되고 서버로 보내지 않음
  - 금리 조회는 금융감독원 오픈 API에서 공시 데이터를 받아오기만 하며 사용자 정보를 보내지 않음
  - 알림은 기기 안에서 예약되는 로컬 알림
  - 생체 인증은 Android가 기기 안에서 처리하고, 앱은 성공·실패 결과만 받음
  - 분석·광고·추적 SDK 없음

## 빌드

- EAS에서 만든 `.aab`(업로드 키는 Expo가 보관)를 올립니다. 이번 파일: `pungcha-1.0.0-vc7.aab` (버전 1.0.0, versionCode 7, [EAS 빌드](https://expo.dev/accounts/zero3181/projects/pungcha-app/builds/72eac8de-cf96-4d1e-9997-8cb58a07c617)).
- 가독화(ReTrace) 파일: `pungcha-1.0.0-vc7-mapping.txt` → App Bundle 탐색기 › 해당 버전 › 다운로드 탭 › ReTrace 매핑 파일 업로드.
- vc7 출시 노트:

```
<ko-KR>
- '굵은 글꼴' 설정에서 글자 끝이 잘리던 문제를 고쳤어요.
- 알림 날짜를 달력에서 바로 고를 수 있어요.
- 메뉴 버튼과 설정 스위치 모양을 다듬었어요.
</ko-KR>
```
- 첫 업로드는 Play Console에서 직접 해야 합니다. 그 뒤에는 서비스 계정 키로 `eas submit` 자동 제출을 연결할 수 있습니다.
