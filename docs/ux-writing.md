# 풍차돌리기 UX 라이팅 원칙

풍차돌리기는 예·적금을 처음 해 보는 사람도 쓸 수 있어야 해요. 앱의 모든 문구는 아래 원칙을 따릅니다.

## 1. 말투

- **해요체**로 씁니다. 친근하되 가볍지 않게 씁니다.
  - 좋아요: `금액을 입력해 주세요` / 피해요: `금액을 입력하십시오`, `금액 입력 바람`
- 할 일을 안내할 때는 `~하세요`, 부탁할 때는 `~해 주세요`를 씁니다.
- 앱을 주어로 말할 때는 `~해 드려요`, `알려드릴게요`처럼 씁니다.

## 2. 짧고 분명하게

- 한 문장에는 한 가지만 담습니다. 길어지면 문장을 나눕니다.
- 결과나 행동을 먼저 말하고, 이유는 뒤에 붙입니다.
  - 좋아요: `이번 달에 또 가입하면 만기가 같은 달에 겹쳐요.`
- 말줄임표(`...`)와 대괄호(`[D-7]`)는 쓰지 않습니다. 진행 중인 상태는 `~하고 있어요`로 씁니다.

## 3. 쉬운 말 먼저

- 풍차 만들기, 할 일 목록, 가입 등록처럼 **처음 쓰는 흐름**에서는 금융 용어를 풀어 씁니다.
  - `총 예치금` 대신 `총 저금액`, `월 납입 총액` 대신 `매달 저금할 금액`
- 계산기·금리 비교 같은 **세부 기능**에서는 금융 용어를 그대로 써도 됩니다. 다만 설명 문구로 뜻을 보태 줍니다.
- `JSON`, `API` 같은 개발 용어는 화면에 쓰지 않습니다.

## 4. 버튼과 확인 창

- 버튼은 동사로 끝냅니다: `만들기`, `저장`, `삭제`, `다시 시도`
- 사용자가 방금 한 일을 알리는 버튼은 사용자 말투로 씁니다: `가입했어요`
- 확인 창의 실행 버튼은 제목의 행동을 그대로 반복합니다. (`계좌 삭제` → `삭제` / `취소`)
- 되돌릴 수 없는 행동에는 `되돌릴 수 없어요`를 붙입니다.

## 5. 오류와 빈 화면

- 무슨 일이 생겼는지와 어떻게 하면 되는지를 함께 씁니다.
  - 좋아요: `금리 정보를 불러오지 못했어요. 잠시 후 다시 시도해 주세요.`
  - 피해요: `알 수 없는 오류가 발생했어요`
- 빈 화면에서는 다음에 할 행동을 알려 줍니다.
  - 좋아요: `첫 적금을 가입하면 여기에 가입~만기 그래프가 생겨요`

## 6. 숫자·날짜 표기

| 구분 | 표기 | 예 |
| --- | --- | --- |
| 문장 속 금액 | 만 원 단위, 단위 앞 띄어쓰기 | `월 10만 원`, `120만 원` |
| 값으로 보여 주는 금액 (목록·입력칸) | 쉼표와 `원` 붙여 쓰기 | `1,200,000원` |
| 기간 | 숫자와 붙여 쓰기 | `12개월`, `6개` |
| 날짜 | 올해는 월만, 다른 해는 연도까지 | `10월`, `2027년 1월`, `10월 1일` |
| 순서 | `N번째` | `2번째 적금` |
| 정보 나열 | 가운뎃점 `·` | `12개월 적금 · 월 10만 원` |

## 7. 띄어쓰기

- 보조 용언은 띄어 씁니다: `입력해 주세요`, `채워 보세요`, `알려드릴게요`(한 단어로 굳은 말은 붙여 씀)
- `원`, `만 원` 같은 단위는 앞말과 띄어 씁니다. `개월`, `개`, `번째`는 붙여 씁니다.

## 8. 용어

한 가지 뜻에는 한 가지 말만 씁니다.

| 쓰는 말 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- |
| 가입 | 은행에서 예·적금 상품에 드는 것 | 개설 |
| 등록 / 저장 | 가입한 계좌를 앱에 기록하는 것 | 가입(앱 기록을 뜻할 때) |
| 계좌 | 내가 가입한 예·적금 하나 | 통장 |
| 상품 | 은행이 파는 예·적금 | 계좌(상품을 뜻할 때) |
| 금리 | 연 이자율 | 이율, 이자율 |
| 예치금 | 예금에 넣은 돈 | 예치 원금 |
| 월 납입액 | 적금에 매달 넣는 돈 (계좌 하나 기준) | 월 불입액 |
| 만기 / 만기일 | 계좌 기간이 끝나는 때 / 그날 | 만료 |
| 해지 | 만기 전에 계좌를 닫는 것 | 중도 해약 |
| 풍차 | 날개 수·금액을 정한 예·적금 묶음 | 풍차 목표, 플랜 |
| 날개 | 만기월이 서로 다른 계좌 하나 | 칸, 슬롯 |
| 할 일 | 풍차를 채우려고 가입해야 하는 순서 | 체크리스트, 미션 |
| 세부 기능 | 계산기·금리 비교처럼 숨겨 둔 고급 기능 | 전문가 모드 |
