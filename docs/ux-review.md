# 풍차돌리기 UX 검토 (2026-10-02)

처음 설치부터 만기 해지까지 한 사람이 1년 동안 겪는 흐름을 따라가며 봤습니다. 시뮬레이터에서 각 화면을 캡처하고 코드의 동작을 함께 확인했고, 실제 사용자 테스트는 아닙니다.

**검토한 흐름:** 설치 → 소개(OOBE) → 풍차 만들기 → 홈(할 일) → '가입했어요' → 계좌 등록 → 다음 달 알림 → 납입 → 만기 → 만기 해지 → 다시 가입

## 요약

처음 시작하는 흐름(소개 → 풍차 만들기 → 첫 가입)은 짧고 분명합니다. 반면 **1년 동안 계속 쓰는 흐름**, 특히 만기와 알림 쪽에 빈 곳이 있습니다. 풍차돌리기의 핵심은 "만기가 오면 다시 가입한다"인데, 이 순간을 앱이 먼저 챙겨 주지 않습니다.

## 우선순위 높음

### 1. 만기된 계좌를 홈에서 먼저 알려 주기
- **지금:** 만기일이 지나도 홈에는 변화가 없습니다. 사용자가 목록에서 그 계좌를 찾아 들어가 '만기 해지'를 눌러야 하고, 그래야 할 일에 "지금 가입하세요"가 다시 나타납니다.
- **문제:** 1년 뒤의 핵심 순간을 놓치기 쉽습니다. 만기 해지를 안 누르면 날개가 계속 찬 것처럼 보여 다시 가입하는 것도 잊게 됩니다.
- **제안:** 만기일이 지난 계좌를 할 일 맨 위에 "3월 적금이 만기됐어요"로 띄우고, 한 번에 [만기 해지하고 다시 가입]으로 이어지게 합니다(해지 기록 → 같은 날개의 가입 시트).

### 2. 적금 납입 알림이 계좌 수만큼 옵니다
- **지금:** '적금 납입일 알림'이 기본으로 켜져 있고, 계좌마다 매달 따로 옵니다. 적금 풍차가 다 돌면 **한 달에 12번** 옵니다.
- **문제:** 대부분 자동이체를 쓰기 때문에 알림이 소음이 되고, 결국 알림 전체를 끄게 됩니다. 그러면 만기·가입 알림도 같이 놓칩니다.
- **제안:** 납입 알림은 기본으로 끄거나, 같은 날 납입하는 계좌를 "오늘 적금 3건 · 30만 원" 한 통으로 묶습니다.

### 3. 적금 풍차의 매달 부담이 커지는 것을 더 분명히
- **지금:** 풍차 만들기의 작은 설명 한 줄("12개월째부터 매달 120만 원")로만 알려 줍니다.
- **문제:** 초보자는 첫 달 10만 원만 보고 시작했다가, 1년 뒤 매달 120만 원이 빠져나가는 것에 놀랄 수 있습니다. 이 앱에서 가장 큰 오해 지점입니다.
- **제안:** 금액 아래에 첫 달 → 6개월째 → 12개월째 금액이 늘어나는 작은 막대를 보여 주고, 12개월째 금액을 굵게 강조합니다.

### 4. 가입을 기록한 뒤 보상 피드백
- **지금:** '저장'을 누르면 시트가 닫히고 끝납니다. 날개가 채워지는 애니메이션은 시트 뒤에서 일어나 거의 보이지 않습니다.
- **제안:** 시트가 닫힌 뒤 홈 위쪽으로 스크롤해 새 날개가 자라는 모습을 보여 주고, 가벼운 진동(햅틱)과 "3월 날개를 채웠어요" 한 줄 토스트를 띄웁니다. 매달 반복하는 행동이라 작은 보상이 습관에 큰 힘이 됩니다.

### 5. 알림 권한을 묻는 타이밍
- **지금:** 첫 계좌를 '저장'하는 순간 iOS 권한 창이 바로 뜹니다.
- **문제:** 왜 필요한지 모른 채 '허용 안 함'을 누르면, 만기·가입 알림이 영영 오지 않습니다(다시 물을 수 없음).
- **제안:** 권한 창 직전에 앱 화면으로 한 줄 이유를 보여 줍니다. 예: "만기 7일 전과 다음 가입 날에 알려드릴까요?" [알림 받기] [나중에]

## 우선순위 중간

### 6. 할 일 목록이 깁니다
- 12날개면 잠긴 단계가 최대 11줄 이어져 화면을 많이 차지합니다.
- **제안:** 다음 2~3단계만 보이고 나머지는 "그 뒤 8단계 더보기"로 접습니다.

### 7. 날개 = 달이라는 규칙을 화면에서 보여 주기
- 지금은 색만 다르고, 어느 날개가 몇 월인지는 알 수 없습니다.
- **제안:** 풍차를 누르면 날개 끝에 월 숫자(1~12)가 잠깐 보이게 합니다. 색 구분이 어려운 사용자에게도 도움이 됩니다(접근성).

### 8. 소개(OOBE) 4장 → 2장
- 1장: 풍차돌리기란 + 장점, 2장: 날개 수와 금액만 정하면 할 일을 알려준다. 나머지(적금 vs 예금)는 풍차 만들기 화면에서 고를 때 알려 줘도 충분합니다.

### 9. 예금 풍차의 기본 금액
- 기본값 1억 2천만 원(12날개)은 처음 보는 사람에게 부담스러운 숫자입니다. 예금은 이미 가진 목돈을 나누는 방식이라, 금액을 "얼마나 있으세요?"처럼 묻고 예시는 낮게(예: 1,200만 원) 두는 편이 자연스럽습니다.

### 10. 은행 로고
- 지금은 은행 대표색과 약칭으로 그린 표시입니다. 공식 로고 이미지를 넣으면 은행을 훨씬 빨리 알아볼 수 있습니다. 공식 사이트에서 받을 수 있는 아이콘은 24곳 중 일부라서 모양과 품질이 고르지 않으므로, 은행별 공식 로고 파일을 따로 모아야 합니다.

## 우선순위 낮음 / 나중에

11. **데이터 백업:** 기기 안에만 저장돼 폰을 바꾸면 백업 파일을 직접 옮겨야 합니다. 기본 iCloud 기기 백업에는 포함되지만, 앱 안에서 iCloud 자동 동기화를 지원하면 더 안심됩니다.
12. **그래프 읽는 법:** 범례를 없애 깔끔해졌지만, 진한 색(지난 기간)과 연한 색(남은 기간)의 뜻은 처음 보는 사람이 바로 모를 수 있습니다. 막대를 누르면 "9개월째 · 3개월 남음" 같은 말풍선을 보여 주는 정도면 충분합니다.
13. **금리 비교의 신뢰:** 공시 기준 기본 금리라는 점과 공시 월을 목록 위에 더 잘 보이게 합니다. 실제 가입 화면의 금리와 다르면 사용자가 앱을 탓하기 쉽습니다.
14. **API 키:** 금융상품한눈에 API 키가 앱에 들어 있어 추출될 수 있습니다. 이용자가 늘면 간단한 서버를 거치게 바꾸는 것을 고려하세요.

## 이번 검토 중에 이미 고친 것

- 금리 비교 순위(22번 이후) 숫자가 두 줄로 떨어지던 문제
- 금리 비교·계산기의 적금/예금 전환이 홈에 의해 되돌려지던 문제
- 가입 알림 패널의 글자 겹침과 정렬
- 금리를 비워 두면 기본 금리로 저장
